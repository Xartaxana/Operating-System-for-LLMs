# RULE_COVERAGE — словесные политики и их сторожа (заведён 2026-07-28 словом оператора)

Карта «правило → что его сторожит → как реализовано». Грузится по
требованию (не boot-путь). Снимок-предшественник — enforcement-gap
аудит (task_reports/2026-07-24_enforcement-gap-audit.md); этот файл —
ЖИВОЙ владелец картины.

ОБЯЗАННОСТЬ ПОДДЕРЖАНИЯ: новый механизм или смена РЕЖИМА срабатывания
существующего — строка/правка здесь ТЕМ ЖЕ коммитом (пара оси 4
SIBLING_MAP); свежесть утверждений — чек 24 калибровки (документ в
списке владельцев). Протухшая строка здесь = находка F-41.

## Режимы срабатывания (легенда)

- **БЛОК-ХУК** — действие не произойдёт: хук харнесса возвращает блок
  до/вместо исполнения (exit 2 + stderr).
- **WARN-ХУК** — действие происходит, но координатор получает сигнал
  в контекст (additionalContext); суждение за ним (D-0063 warn-first).
- **ГЕЙТ КОММИТА** — сделать можно, закоммитить нельзя: pre-commit /
  commit-msg скрипт валит коммит.
- **ВСПЛЫТИЕ** — SessionStart печатает факт в контекст каждой новой
  сессии (не блокирует, но неизбежно видим).
- **ЧЕК N** — номерная проверка еженедельной калибровки; единственный
  дом всех номеров — чек-лист PROCESS/WEEKLY_CALIBRATION_PROTOCOL.md
  («механизм → нарушение → как проверить»); расшифровка упомянутых в
  этом файле номеров — справочник в конце документа.
- **AI-СЛОЙ** — соответствие ПО СМЫСЛУ судит ярус выше (приёмка Lead,
  критик, судья); код гарантирует встречу, AI — вердикт (D-0063).
- **КОНФИГ** — нарушение исключено конфигурацией (харнесс не даст).
- **ЭКЗАМЕН** — регрессионный набор с закреплённым ключом.
- **ДИСЦИПЛИНА+ДЕТЕКТОР** — машинной встречи нет сознательно; отказ
  ловит НАЗВАННЫЙ чек (D-0064; без детектора — не механизм, D-0049).
