- Р2 порог: рек. для чека — доля с полом (≥3 spec И ≥40% rejected

- Р3 окно: рек. (iii) с последнего calibrated для чека, 7 дней для warn.
- Р4 видимость в чеке 11(в) при ветке А: рек. да (иначе R10(в) не закрыт).
- Р5 «тихие» spec-дефекты (R11(n) говорит «reject OR finding»):
  рек. (а) только rejected(spec) + явная строка пробела; маркер для
  признанных без реджекта — в очередь Lead.
- Р6 ретро/чужой деплой: рек. только журнал OS; ретро считать, числом
  отдельно.
- Р7 владение посадкой: код+тесты билдер; реестр/протокол/карта — Lead.
- Р8 нормативное последствие срабатывания: рек. пока только
  видимость (норма поверх одной точки — класс «объявление вместо

- Р9 ветка Б куда: счёт+печать в counts, вердикт глазами Lead;
