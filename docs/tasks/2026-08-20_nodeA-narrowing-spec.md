## 8. Края поведения (названы, не оставлены на догадку)

1. **Смешанный коммит (форма + норма)** — содержателен ЦЕЛИКОМ; строка
   «форма:» на нём незаконна; дробление коммита ради льготы — тоже.
2. **Правка, чью содержательность нельзя установить по диффу** —
   fail-closed: не доказана, значит содержательная. Для R11a и трёх
   прозаических секций машинного пина НЕТ, единственный законный путь
   — критик-вердикт; его отсутствие = находка, а не «наверное, форма».
3. **Skip-класс, перешедший из концессии в лазейку** — объявляет
   калибрующий Lead ЗАПИСАННОЙ находкой, проспективно; обратный
   перевод той же формой. До находки класс остаётся концессией,
   сколько бы раз ни повторился (число — обязательная строка прогона).
4. **Ретроактивность — НЕТ** (Р3-А): обе формулировки действуют с
   посадочного коммита; окно №8 не пересуживается.
5. **Обе строки сразу** («форма:» И строка Runs log) — дефект формы,
   читается как содержательный.
6. **Пустое окно.** 14(ж): «правок названных путей в окне нет» только
   с ПОЗИТИВНЫМ КОНТРОЛЕМ той же формы. Чек 22: сохранена явная строка
   + новая обязанность назвать число повторов концессий (включая 0).
7. **Отсутствующий вход:** `norm_keys.json` отсутствует/не парсится →
   доказательство (i) недоступно, остаётся (ii); молча считать форму
   доказанной запрещено.
8. **Конфликт пары требований внутри чека 22:** порог >=3 против
   сужения — для КЛАССА-ЛЬГОТЫ оба слоя работают независимо; для
   СТОЯЧЕЙ КОНЦЕССИИ порог остаётся сигналом, но законное прочтение —
   только ветвь «правило не соответствует практике».
9. **Временной край:** `2026-08-20_nodeA-keyrun.py` не существует на
   момент спеки — создаётся ТЕМ ЖЕ коммитом; до его создания витнесс
   R11.l невозможен.
10. **Позиционный край:** сужающий абзац 14(ж) вставляется ПОСЛЕ
    перечисления путей и ПЕРЕД обязанностью «Ни одной строки =
    находка». ИНВАРИАНТ, который позиция обязана сохранить:
    fail-closed остаётся достижимым, хвост «Также…»/«Живость…»
    остаётся последним и не отрезается; шапка остаётся первой строкой
    после закрывающего `**`; ни одна новая строка не начинается
