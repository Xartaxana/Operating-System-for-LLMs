## K2 — словарь write-глаголов (общий потолок, dispatch_gate.py:792-794)

`WRITE_INDICATORS_RE` — один скомпилированный объект, потолок ТРЁХ
слоёв (WRITE_QUOTED :2113; QUOTED_OWNS owns_gate:1752; BLIND_OWNS
owns_gate:1761) И самого блока is_write (:1154→decide :1196).
Решение Lead по составу:
- добавить `\bпосади\b` и `\bвнеси\b` — голыми альтернативами;
- «добавь» — ТОЛЬКО связанной формой: `добавь` + в той же строке
  (без перевода строки) в пределах ~60 символов файловый объект
  (`файл|файла|строку|строки|запись|блок|секцию|раздел|путь`).
  Голое «добавь в дайджест/отчёт» НЕ матчится (иначе ложный БЛОК
  read-only диспатчей — ось 15).
Края (батарея НА границе и ЗА ней, R11(e)): «посади узел» → матч;
«внеси правку» → матч; «добавь строку в X.md» → матч; «добавь в
дайджест вывод» → НЕ матч; «добавь\n…файл» (перевод строки между) →
НЕ матч; регистр (ДОБАВЬ, Посади) → матч (re.IGNORECASE уже стоит);
61+ символов между «добавь» и объектом → НЕ матч (граница названа —
тест AT и BEYOND).
Обязанности: (а) комментарий-пин узла A (dispatch_gate.py:1216-1218
«регексы/порог НЕ меняются») касается GIVEN-регексов — если его
формулировка шире, СУЗИТЬ до факта; (б) grep четырёх старых форм по
tools/warn_layers.json — если записи слоёв цитируют состав словаря,
обновить той же правкой; пусто — доложить с позитивным контролем.

## K4 — проза в owns-экстракторе (owns_gate.py)

только его). Края: элемент-глоб с пробелом внутри бэктиков; два
бэктик-спана в одном элементе → два элемента; пустой owns после
