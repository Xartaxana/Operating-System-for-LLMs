нормализованном \r\n→\n, MULTILINE); bpr = bytes/records (целое;
records==0 → «—»); дельты к прошлой записи сайдкара. Вердикты:
OK ≤ 95% порога; WARN (95%..порог]; BREACH строго >; «—» без порога;
MISSING/ПУСТ/ДЕФЕКТ — края. ДЕЛЬТА-ПРАВИЛО (всегда, без порогов):
Δbpr>0 при Δrecords≤0 → «РОСТ ВГЛУБЬ: <path> +N Б/запись при <=0
новых записей». Агрегат: сумма байт corpus, порогов k/12, BREACH/
WARN, дельта суммы.
