### 4.3 Учёт байт и адреса
«К чтению» = протокол (ядра — обычная часть диапазона) ПЛЮС тела
живых чеков (Р2(A)); секционированное тело — преамбула + секции
живых подпунктов. Перед ИТОГ: `ТЕЛА К ЧТЕНИЮ: <путь> (<Б>, предикат
<pred> -> <наблюдено> из <контроль>); ...` и `ТЕЛА ПРОПУЩЕНЫ:
<путь> (<причина>; skip-streak <n>/3)`. ИТОГ: `к чтению N Б из M Б
(X%) · из них тела T Б · принудительно F Б · гейт (а) ≤P Б
(храповик от замера <дата>, окно <тип>, K=<K>): ВЗЯТ/НЕ ВЗЯТ (±d)`.

### 4.4 Skip-каунтер
Носитель — существующий сайдкар logs/calibration_prepass.jsonl;
запись получает `kind` («калибровка»/«ad-hoc») и `bodies:
{id: ПРОЧИТАНО|ПРОПУЩЕНО|ПРИНУДИТЕЛЬНО}`. Классификация Р7(A):
kind=калибровка если --window-start == ts последнего calibrated
ЛИБО флаг --calibration; журнал недоступен → калибровка. Streak =
подряд идущие последние калибровки с ПРОПУЩЕНО; скан стопается на
ПРОЧИТАНО/ПРИНУДИТЕЛЬНО; записи без bodies пропускаются. streak>=3
→ тело ПРИНУДИТЕЛЬНО живо, печать: `ПРИНУДИТЕЛЬНО ЖИВ: <id> — тело
пропущено 3 калибровки подряд (skip-каунтер), предикат <pred>
ложен`; фиксация ПРИНУДИТЕЛЬНО обнуляет streak. Принудительные
байты в вердикт гейта не входят (Р10(A), P3).

### 4.5 Сторож живости предикатов (класс «молчаливый ноль»)
Каждый ПУСТ body-предиката несёт `X из Y`, Y — позитивный контроль
той же формы (git.paths/pathset — число коммитов окна без pathspec;
Y==0 → вторая ступень: git rev-parse --git-dir + вердикт «окно без
коммитов, форма жива»). git недоступен → ЖИВ fail-closed с
причиной. Красная половина: monkeypatch _run_git → None и → "";
тело живо, «0 из 0» без контроля невозможен.

### 4.6 Сверка пары шапка↔тело (секция --check-form, Р11(A))
(1) тело существует, читается, LF, непусто; (2) путь относительный,
внутри репо, ровно один чек на файл; (3) шапка тела несёт владельца
и правило ведения (маркеры-строки); (4) номер в теле == номеру
шапки; (5) секционированное тело: каждая строка в ровно одной
секции/преамбуле; id секции существует под-шапкой; под-шапка без
секции легальна, секция без под-шапки — дефект; (6) body у
под-шапки — дефект; (7) чек с body обязан иметь непустое ядро.

### 4.7 Fail-closed
— Пре-пасс не отработал: перехват в main() → `ПРЕ-ПАСС НЕ
ОТРАБОТАЛ: <класс> — ЧИТАЕТСЯ ВСЁ: протокол + <перечень
PROCESS/checks/ ОБХОДОМ КАТАЛОГА>` + `ГЕЙТ (а): НЕ ИЗМЕРЕН`,

— Сайдкар нечитаем/битая строка: ВСЕ тела принудительно живы +
`САЙДКАР ДЕФЕКТЕН (<n> битых строк)`; read_registry считает битые
строки (сегодня молча глотает — правится; determine_mode не
трогается).
— Тело отсутствует при живом вердикте: `ТЕЛО ОТСУТСТВУЕТ: <путь> —

### 4.8 Храповик гейта (а)

## 7. Края

### 7.1 Лимиты
| Лимит | На границе | За границей |
|---|---|---|
| skip-streak 3 | ровно 3 → ПРИНУДИТЕЛЬНО + причина | 2 → ПУСТ легален; 4 → форсируется + строка «счётчик перешагнул порог — разобрать» |
| порог P | к чтению == P → ВЗЯТ | P+1 → НЕ ВЗЯТ (+1 Б), число Архитектору |
| монотонность GATE_A_HISTORY | новое == прежнему → плато легально | новое > прежнего → тест красный, сообщение называет легальный выход |
| шапка 300 Б | 300 → PASS | 301 → дефект; лечение — сокращение предиката, НЕ поднятие лимита |
| MAX_FIELDS_TOTAL 9 | 9 → PASS | 10 → дефект |
| порог выноса 3 000 Б | ровно 3 000 → выносится | 2 999 → остаётся, строка «вынос не применён» |
| К3 15 000 Б | ровно → взят | 14 999 → СТОП + развилка (P1) |
Байтовые цели ядер — приёмочные числа, тест на границе сознательно
не заводится (рамка не проигрывает числу).

### 7.2 Темпоральные (R11.c)
PROCESS/checks/ создаётся ТЕМ ЖЕ коммитом, что первое поле body;
до — body запрещён; указатель и тело — один коммит. Мир до W4-2:
код посажен, body-шапок нет → поведение идентично (К2, тест (п)).
Мир до W4-3: порог 57 500 со старым провенансом — задуманное
состояние. Сайдкар до W4: записи без bodies игнорируются, первая
калибровка стартует со streak 0. Замер до/после — одинаковая
доступность источников.

### 7.3 Позиционные (R11.d)
body после status и до cand (FIELD_ORDER); шапка чека — первой
строкой после закрывающего ** (AM-1 П1); указатель — ПОСЛЕДНЕЙ
строкой ядра (читатель узнаёт о теле до вывода «чек прочитан»);
ядро на месте прежнего тела (порядок §0→§5 и SECTION_BY_CHECK не
меняются; читатель ядра не может прийти к более РАЗРЕШИТЕЛЬНОМУ
выводу); сверка пары в run_check_form ПОСЛЕ разбора шапок, ДО
rules-форварда.

### 7.4 Пустой/отсутствующий вход
Пустое окно — штатный режим (тела 26/18 живы, тело 13 не читается);
журнал отсутствует → журнальные предикаты живы, kind=калибровка;
git недоступен → body-предикаты живы с причиной; сайдкар
отсутствует → streak 0 + строка, НЕ форсирование; битый →
форсирование ВСЕХ тел; тело отсутствует → дефект + ядро + находка;
каталог отсутствует при живых body → тот же класс по каждому чеку,
перечень из шапок с пометкой; пустой список ключей → скрипт падает.

### 7.5 Конфликтные пары
P1 рамка сильнее К3 (СТОП, не добор). P2 греп чека 26 расширяется
тем же ходом. P3 гейт без принудительных тел. P4 при неотработавшем
пре-пассе `ГЕЙТ (а): НЕ ИЗМЕРЕН` (не «ВЗЯТ»). P5 id тела = номер;
стаб ретирования — в ПРОТОКОЛЕ (часть ядра). P6 разрыв ряда bpr
объявляется. P7 чек 24 — н-п строкой. P8 пол падает ровно на
узость предикатов — проверяется замером, не риторикой.
