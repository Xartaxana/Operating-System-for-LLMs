### Акцептанс-критерии
**A-К1.** Форма (а) — сиблинги D-0069: токен, единственные вхождения которого
в строке-объявлении сдачи-сиблингом, исключается. **Признак — развилка Р4, НЕ ЗАКРЫТА.**
**A-К2.** Форма (б) — строка проверочного прогона: токен, каждое вхождение
которого непосредственно после запускающего слова (`python`, `pytest`),
исключается ЕСЛИ нет вхождения в `given`.
**A-К3.** Форма (в1) — шаблон имени: токен с метапеременной-заглушкой (≥2
одинаковых заглавных латинских, `<...>`, `{...}`) исключается ВСЕГДА и
безусловно. Граница лимита ровно 2 символа.
**A-К4.** Форма (в2) — список НЕ-ЦЕЛЕЙ: `_MANIFEST_SECTION_HEADER_RE`
расширяется русскими синонимами `не-цели|не цели|non-goals`, секция получает
СОБСТВЕННУЮ метку `"non-goals"` вместо слияния в `"other"`.
**A-К5.** Все исключения ВНУТРИ `_filter_given_candidates()`, ПОСЛЕ извлечения
кандидатов, ДО `os.path.exists`. Ни одно не может ДОБАВИТЬ токен в `missing`.
**A-К6. «Given выкупает».** Токен, названный хотя бы раз внутри `given`/`дано`,
не исключается правилами A-К1/A-К2/A-К4 (A-К3 безусловно: шаблон имени не есть
путь ни в какой секции). Форма дословно та же, что в `_tokens_outside_owns_section()`.
**A-К7.** `ROLE_TYPE_WARN_UNKNOWN_ROLE` расщепляется на
`..._PROJECT` (проектная роль без файла) и `..._BUILTIN_TYPE` (встроенный тип).
Обе ОБЯЗАНЫ начинаться литералом `ROLE-TYPE WARN:` — иначе рвутся реестр и
`docs/rule_coverage/RC-01.md`:58. Обе несут ТРИ вещи пункта 8. Список
встроенных типов — Р-А3.
**A-К8. Замер снятого.** Прогон печатает, сколько токенов снято каждым
правилом. Число «снято всего» ОБЯЗАНО быть > 0 и включать поимённо хотя бы один
из токенов, названных критиком (`tools/negative_lint_md.py`,
`tools/session_context_autoboot.py`, `PROCESS/checks/CHK-NN.md`). Не покрыт ни
один — правка не решает задачу, `rejected`.
