## СПЕКА A — модуль (этап 1, t-507)

Файлы: tools/md_regions.py + tools/test_md_regions.py (новые, никем
не импортируются до посадки потребителей → D-0069 не задет, кладутся
билдером напрямую; в невод НЕ входят до первого потребителя — Р8(б)).

A1. Контракт: ФАКТЫ, не вердикты. Публичная поверхность ТОЛЬКО:
константы видов (KIND_PROSE/KIND_FENCED/KIND_INLINE_CODE/
KIND_BLOCKQUOTE + зарезервированные KIND_NOTES/KIND_EMBEDDED_DOC),
тип Region, scan(), line_kinds(), kind_at(), константы лимитов.
Никаких should_ignore/is_quoted_claim/SILENCE_KINDS/политик.
Пин-тест test_public_api_surface_is_facts_only — дословный список
dir(); новое публичное имя валит тест (детектор «в сканер поехала
политика»).

A2. API:
Region = NamedTuple(start, end, kinds: tuple, line_start, line_end,
unterminated: bool, info: str);
scan(text) -> ScanResult(regions, degraded: bool, reason: str);
line_kinds(text) -> list[tuple];  kind_at(result, offset) -> tuple.
Инварианты (тест на каждый): (1) полное непересекающееся покрытие
(проза тоже регион; конкатенация регионов == исходный текст
побайтно); (2) смещения в ИСХОДНОМ тексте, splitlines(keepends);
CRLF/CR/BOM/без хвостового \n — склейка держится; (3) вложенность
стеком снаружи внутрь ("blockquote","fenced"); (4) чистая функция.

A3. Распознавание v1 (CommonMark-lite, отступления явно): фенс ```/
~~~ (≤3 пробела отступа, закрытие тем же символом длиной ≥
открывающей; info сохраняется, семантики не несёт); цитата > (≤3
пробела; глубина не моделируется); инлайн-код — парные
backtick-серии ОДНОЙ строки (разорванная переводом пара — проза,
пин); отступный 4-пробельный код НЕ распознаётся (задокументировать
+ тест); ленивое продолжение цитаты НЕ реализуется (Р3(б), пин).

A4. Лимиты (по ДВА теста: на границе/за): MAX_TEXT_CHARS=2_000_000;
MAX_REGIONS=20_000; MAX_LINE_INLINE_SPANS=200. Деградация ВСЕГДА в
сторону «всё — проза» (= сегодняшнее поведение сторожей):
degraded=True + reason, никакого расширения зоны молчания.

A5. Битый вход fail-open: None/не-str → ScanResult([], True,
"not_a_string") без исключения; "" → ([], False, ""); текст из
одного \n / одного открывающего фенса / одного > — валидны,
покрытие держится. Модуль не ловит исключения сверх этого;
потребитель оборачивает своим try (инвариант И-0 этапа 2).

Края §5 (тест на каждый, имена тестов с меткой края): (а) > внутри
фенса — цитаты нет; (б) фенс в цитате — ("blockquote","fenced");
фенс не закрыт до конца цитаты → закрывается концом цитаты,
unterminated=True; (в) незакрытый фенс — модуль отдаёт unterminated,
вердикта не выносит (у сторожей партии 1 дефолт «проза → сторож
говорит», у owns_gate противоположный — расхождение записывается в
докстринг модуля явно); (д) инлайн внутри прозы — спаны
prose|inline_code|prose, покрытие держится; (е) line_kinds отдаёт
только блочный стек, инлайн виден только через scan() (докстринг +
тест); (ж) degraded = «всё проза» — не политика, а отказ от разметки.

Батарея §6 (модульная часть): 1 МБ открывающих фенсов (время, не
квадратично); 10 000 backtick в строке (лимит спанов); вложенность
> x50; фенс 200 backtick закрытый 199 (нет) и 201 (да); суррогаты/
кириллица/эмодзи вне BMP (смещения в символах, склейка); CRLF/CR/
смешанные/BOM/без \n; None/bytes/dict/int fail-open; фенс в ячейке
таблицы; замер: полный scan 1 МБ ≤ 150 мс (бюджет, вывод замера в
witness).

## СПЕКА B — этап 2 (партия 1, отдельный диспатч после посадки модуля)

И-0: любой отказ модуля (ImportError/исключение/degraded) → сторож
ведёт себя КАК СЕГОДНЯ побайтно (тест monkeypatch-подменой scan на
бросающую). И-1 (Rule #1, ленивость): сканер зовётся только после
дешёвого предфильтра (тест-счётчик: без маркеров вызовов 0).
B1 negative_lint: вызов в find_violations ПОСЛЕ поиска маркеров;
политика сторожа: fenced/blockquote — не нарушение, inline_code —
нарушение; ПОЗИЦИОННЫЙ ИНВАРИАНТ: окно ±3 по ИСХОДНЫМ индексам
(контроль в цитате гасит негатив в прозе — тест пары); незакрытый
фенс = проза (урок «silence looks like success»).
B2 claim_control_gate: вызов после path-scoping и маркер-хита;
политика: fenced/blockquote не порождают окно и не засчитывают
токены, inline_code засчитывается; ПОЗИЦИОННЫЙ ИНВАРИАНТ: пять
граничных регексов (:493-499) не меняются ни байтом, регион — шестая
граница; пины t-022/F5 зелены, названы в witness.
Форма: сиблинги negative_lint_md.py / claim_control_gate_md.py +
тесты с MODULE_UNDER_TEST; посадка Lead байт-копией +
hook_liveness_probe; тем же ходом посадки — модуль в
MECHANISM_PREFIXES (Р8(б), пункт чек-листа) — механизменный коммит.
Негативный контроль дискриминации: прогон с отключённым фильтром
красный на парах «в цитате/в прозе» (§8 п.4 драфта).
