# Calibration History (архив)

Назначение: известные поправки счёта / разрывы базы / прежние
редакции норм калибровки — данные, нужные при СЧЁТЕ (интерпретации
конкретных прошлых чисел, сверке с прежней формулировкой нормы), не
при каждом прогоне. Живая норма и её сторож остаются в
`PROCESS/WEEKLY_CALIBRATION_PROTOCOL.md`; сюда уезжает только
история, на которую протокол ставит именованный указатель.

Владелец: Lead.

Правило ведения: append по датам (новые записи добавляются в конец,
существующие не переписываются и не переставляются); сюда уезжает
ИСТОРИЯ — прежние редакции норм, разрывы базы сравнения, разовые
известные поправки счёта — а не действующие нормы; переименование
файла и заголовков секций запрещено (на них ссылаются по имени файла
из протокола). Формат — LF, UTF-8 без BOM.
